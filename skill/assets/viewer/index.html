三步完成一次动作修改

















01



找到那个瞬间


选择动作、放慢播放，按空格暂停。你可以点一下身体定位部位，也可以直接用语言描述。







02



说出你想要的变化


一句自然的话就可以。默认修改整个动作；只想修改一小段时，再展开时间范围。







03



用同一个镜头看结果


Agent 完成后，候选会回到动作台。并排检查、逐帧比较，保留原版或继续提出意见。






初始角色是原创教学人偶。可以用“先试一次本地微调”完成第一轮，无需连接 AI。三维预览不包含游戏中的自定义衣料、IK 和战斗逻辑。














复用你正在使用的 Agent


Skill 负责上下文、工具和检查，审美与诊断交给 Agent。页面提交任务并不会默认唤醒当前聊天。


使用任务面板的“连接 Codex 并开始修改”，可通过已有 CLI 授权处理本地任务。也可以把任务命令复制到当前 Agent 对话，或连接 Skill 自带 MCP 工具。


任务未被领取时会明确显示“等待 Agent”；执行失败会保留原因。页面不会把本地数值调整伪装成 AI 修改。
